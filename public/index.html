✏️ 5. 自訂基本面與財報覆寫教學

編輯 data/custom_estimates.json 的 overrides 區塊，打造個人專屬估值模型：

{ "overrides": { "NVDA": { "eps_current": null, "eps_next": null, "base_per": 15.0, "compound_years": 3, "per_high_avg": 34.0, "per_low_avg": 20.0, "earnings_date": "2026-08-26" } } }

欄位留 null 或刪除該鍵時，系統自動以 yfinance 抓取並計算。可覆寫：eps_current / eps_next / base_per / compound_years / per_high_avg / per_low_avg / earnings_date。
